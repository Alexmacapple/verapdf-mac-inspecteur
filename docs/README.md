Les spécifications sont une rétro-ingénierie du code de cette version, réalisée
le 15 novembre 2026. Elles décrivent l’existant ; elles ne constituent pas un
cahier des charges écrit avant le développement. Une capacité non testée ne
devient pas acquise parce qu’elle figure dans une intention de conception.

Les rapports de revue restent des instantanés historiques : les anciens noms,
chemins et réserves y sont conservés. La recette indique les corrections ultérieures.
